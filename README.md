# المنصة التعليمية الموحدة (Unified Study Platform)

منصة دراسية جامعية موحّدة تجمع المقررات الدراسية (TOC / RM / SEC / SE / PM / PHY) في تطبيق واحد سريع ومستقر مبني بـ React 19 + TypeScript + Vite، مع كاش محلي فائق السرعة عبر IndexedDB، دعم PWA والعمل الكامل دون اتصال، قارئ الكتب المرجعية العمودية، وطبقة مزامنة سحابية اختيارية مع Supabase.

## الأقسام والميزات

1. **عارض السلايدات وقارئ الكتب المرجعية العمودية (Adaptive Dual Engine):**
   - **وضع السلايدات الأفقية:** عرض متجاوب مع تحميل تدريجي تلقائي، لايت بوكس باللمس والتقريب (`Pinch` / `Pan` / `Ctrl+Wheel`)، وذاكرة موضع.
   - **وضع الكتاب المرجعي العمودي (للصفحات الطولية A4 مثل `phy` أو أي مقرر يُضاف بنمط كتاب):**
     - **3 أوضاع تخطيط:** «الكتاب + الشرح» ثنائي اللوحة (صفحة ثابتة Sticky بجانب الترجمة والشرح)، «قراءة متصلة» بطول الصفحة الكامل دون قص 16:9، و«صفحتان متقابلتان» ككتاب مفتوح على الحواسيب.
     - **فلاتر راحة العين للورق:** أصلي، ورق دافئ (Sepia)، ووضع ليلي ذكي يعكس بياض الورق دون تشويه المخططات.
     - **أدوات القارئ:** قفز سريع لرقم الصفحة، متابعة آخر صفحة قرأتها، شريط تقدم قراءة الفصول، ولايت بوكس يدعم «ملاءمة العرض» (`F`) وتبديل الورق (`C`).
2. **الملخص النظري:** كتل `p / list / table / warn / tip / formula`، روابط شرائح، روابط قفز للاستوديوهات، بحث عربي ذكي، وتتبع الأجزاء المقروءة.
3. **ملخص الملخص 80/20:** كبسولات، مصفوفة حسم، شبكة فخاخ، حل بالعين، واختبار فخاخ تفاعلي.
4. **الجداول الشارحة:** فلترة أهمية الصف (1–5)، حفظ الجداول، نسخ Markdown سليم، بحث عربي مطبّع، وتحويل تلقائي لبطاقات على الهاتف.
5. **بنك الأسئلة والمحاكي الامتحاني:**
   - نماذج رسمية وموثقة، درجات حية، خريطة إتقان، دمج ومزامنة دلالية للأسئلة التوأم، لخبطة ذكية تحمي الأسئلة الموضعية (`a & b` / `All of the above`)، علامات ملونة قابلة للتسمية، وتصدير/استيراد النسخ الاحتياطية (`JSON`).
   - **محاكي الاختبار:** وضع «امتحان حقيقي» (تصحيح بعد التسليم) أو «تدريب فوري»، مؤقت عد تنازلي أو ساعة إيقاف، أعلام مراجعة، وتقرير نقاط ضعف تفصيلي.
6. **البحث الشامل (`Ctrl+K`):** بحث عربي مطبّع (أ/إ/آ، ة/ه، بدون تشكيل) عبر جميع الأقسام: الأسئلة، الشرائح/صفحات الكتاب، الجداول، الملخص، ملخص الملخص، التعاريف، المعجم، والأنماط.
7. **الاستوديوهات التفاعلية:** محاكيات DFA/NFA/Powerset/PDA/TM لـ TOC، مصفوفة المنهجية لـ RM، واستوديوهات التشفير/الوصول/هندسة البرمجيات/إدارة المشاريع/الفيزياء الكمية.

## البنية التقنية

- **الواجهة:** React 19 + Vite 6 + TypeScript (`strict`, `noUnusedLocals`, `noUnusedParameters`) مع تقسيم حزم تلقائي (`React.lazy`) و`ErrorBoundary`.
- **البيانات:** Dexie.js (IndexedDB) + حزم JSON ثابتة + بوابة تحقق `npm run check:data` + مزامنة اختيارية محمّلة كسولاً مع Supabase.
- **الأنماط:** `src/styles/legacy-master.css` + `src/styles/superset.css`.
- **الصور:** صيغة `WebP` محسّنة تحت `public/slides/{subject}/...` ومعمل أمن المعلومات في `public/slides/sec/lab/...`.
- **معيار صفر إيموجيات:** 100% أيقونات SVG خطية.

## الأوامر

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# فحص سلامة البيانات والصور والروابط (بوابة CI)
npm run check:data

# إعادة بناء حزم المقررات من العارضات المرجعية
npm run build:data

# بناء الإنتاج والتحقق من TypeScript
npm run build
```

> ملاحظة: عند تحديث حزم البيانات يُرفع `BUNDLE_VERSION` داخل `scripts/build-bundles.mjs` و`APP_DATA_VERSION` في `src/lib/dataService.ts` لتحديث الكاش المحلي تلقائياً.

## Supabase (اختياري)

المخطط موجود في `supabase/schema.sql` ويشمل الجداول: `subjects`، `lectures`، `slides`، `study_modules`، `question_models`، `questions`، `user_study_progress`. في حال عدم ضبط متغيرات البيئة لا يتم تحميل مكتبة Supabase أصلاً ويعمل التطبيق بالكامل محلياً عبر IndexedDB.
