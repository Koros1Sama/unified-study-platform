# المنصة التعليمية الموحدة (Unified Study Platform)

منصة دراسية جامعية موحّدة تجمع أفضل ما في العارضات السابقة (TOC / RM / SEC / SE / Viewer_TEMPLATE) في تطبيق واحد مبني بـ React 19 + TypeScript + Vite، مع كاش محلي سريع وطبقة مزامنة اختيارية مع Supabase.

## الأقسام والميزات

1. **السلايدات:** عارض مصغّر مع لايت بوكس للزوم/السحب، وترجمات وشروح قابلة للإظهار، وذاكرة موضع.
2. **الملخص النظري:** كتل `p / list / table / warn / tip / formula`، روابط شرائح، وروابط قفز للاستوديوهات، وتعليم الأجزاء كمقروءة.
3. **ملخص الملخص 80/20:** كبسولات، مصفوفة حسم، شبكة فخاخ، حل بالعين، اختبار مصغر، وبطاقات/صح وخطأ/خط زمني بحسب المادة، مع بحث وتوجيهات أستاذ المقرر وتتبع مراجعة.
4. **الجداول الشارحة:** فلترة أهمية الصف (1-5)، حفظ الجداول، بحث، ملاحظات شارحة، ضبط تلقائي للأعمدة، وتجاوب كامل يحوّل الجدول إلى بطاقات على الهاتف.
5. **بنك الأسئلة:** نماذج وتوثيق مصدرها، درجات حية، خريطة إتقان بحسب المحاضرة، فلترة (الكل/غير محلولة/خاطئة/صحيحة/معلّمة)، دمج التوائم، بحث، تصفية بأرقام الأسئلة، جلسة إعادة للأخطاء، وتعليم الأسئلة.
6. **بطاقة السؤال:** تعليل الخيار الصحيح، تفنيد كل خيار خاطئ (علة الاستبعاد + متى يكون صائباً)، تكتيك الحل السريع، دعم الأسئلة المقالية بإجابة نموذجية، ووسم الأسئلة التنبؤية والمصادر.
7. **المستكشف:** بحث متعدد النطاقات (السؤال/الخيارات/الكل) مع تظليل عالي التباين، عرض مدمج/كامل، وقفز مباشر إلى السؤال.
8. **الاختبار:** نطاق من البنك، مؤقت عد تنازلي أو ساعة إيقاف، تعليم الأسئلة، لوحة أسئلة بحالات، تقدير A+/A/B/C/D/F، إتقان بحسب المحاضرة، مراجعة مفلترة، وسجل محاولات.
9. **بنك التعاريف:** بطاقات Terms + 5-Second Triggers + Exam Pitfalls، بحث وتصنيفات، أهمية 1-5، وضع فلاش كارد، وتعليم الإتقان.
10. **المعجم:** معجم إنجليزي-عربي أبجدي للمصطلحات والعبارات مع بحث وتحميل تدريجي.
11. **مختبر الأنماط (RM):** قواعد حسم مستخرجة من البنك مع دقة كل قاعدة وحالاتها واستثناءاتها.
12. **الملحق العملي (SEC):** عزل كامل لسلايدات المعمل عن النظري، بجلسات وبحث ولايت بوكس ورابط للعارض المستقل.
13. **الاستوديوهات التفاعلية:** محاكيات TOC/RM الأصلية، ومحاكيات جديدة بأيقونات SVG: التشفير (قيصر/Diffie-Hellman/التوقيع)، BLP/Biba، البرمجيات الخبيثة والمكدس، اختيار نموذج العمليات، McCabe، V&V، ومصفوفة المخاطر.

## البنية التقنية

- **الواجهة:** React 19 + Vite + TypeScript (strict).
- **البيانات:** Dexie.js (IndexedDB) + ملفات JSON ثابتة + مزامنة اختيارية مع Supabase.
- **الأنماط:** `src/styles/legacy-master.css` (النظام الأصلي) + `src/styles/superset.css` (طبقة الميزات الجديدة).
- **الصور:** `public/slides/{subject}/...` ومعمل أمن المعلومات في `public/slides/sec/lab/...`.
- **معيار صفر إيموجيات:** 100% أيقونات SVG خطية.

## الأوامر

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# إعادة بناء حزم المواد الأربع من العارضات المرجعية
npm run build:data

# بناء الإنتاج والتحقق من TypeScript
npm run build
```

> ملاحظة: عند تغيير بيانات المصدر يجب رفع `BUNDLE_VERSION` داخل `scripts/build-bundles.mjs` لإجبار المتصفح على تحديث الكاش المحلي.

## Supabase (اختياري)

المخطط موجود في `supabase/schema.sql` ويشمل الجداول: `subjects`، `lectures`، `slides`، `study_modules`، `question_models`، `questions`، `user_study_progress`. في حال عدم ضبط متغيرات البيئة يعمل التطبيق بالكامل من الملفات المحلية وIndexedDB.
